# Meal Finder

A responsive recipe finder built with HTML, CSS and JavaScript using TheMealDB API.

## Features
- Search meals by name
- Browse meal categories
- Open categories from the menu in a new browser tab
- View meal details, ingredients, measures and instructions
- Responsive layout for desktop, tablet and mobile

## Files
- `index.html` - main page
- `category.html` - category page opened in a new tab
- `app.js` - main page logic
- `category.js` - category page logic
- `style.css` - shared styling

## API
The project uses TheMealDB endpoints for categories, meal search, category filtering and meal details.
