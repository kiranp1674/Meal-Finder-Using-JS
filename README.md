# 🍽️ Meal Finder

A responsive **Meal Finder web application** built using **HTML, CSS, and JavaScript**. The application uses the **TheMealDB API** to search for meals, browse categories, and display detailed recipe information.

## ✨ Features

* 🔍 Search meals by name
* 🍲 Browse meal categories
* 🖼️ Display meal cards with images
* 📖 View complete meal details
* 🧂 View ingredients and measurements
* 👨‍🍳 View cooking instructions
* ☰ Category navigation menu
* 🔗 Open categories in a new browser tab
* 📱 Responsive design for desktop, tablet, and mobile
* ⚡ Dynamic data loading using JavaScript Fetch API

## 🌐 API Used

This project uses the **TheMealDB API** to retrieve recipe information.

Main API operations include:

* **Search meals by name**
* **Get meal categories**
* **Filter meals by category**
* **Get meal details by ID**

API documentation:

[TheMealDB API](https://www.themealdb.com/api.php)

## 🔎 How It Works

### Search Meals

Enter a meal name in the search box.

The application sends the search request to TheMealDB API and dynamically displays the matching meals.

### Browse Categories

The application loads available meal categories from the API and displays them as category cards.

### View Meal Details

Clicking a meal displays information such as:

* Meal name
* Category
* Area/Cuisine
* Ingredients
* Measurements
* Cooking instructions

### Category Navigation

Selecting a category from the navigation menu opens the selected category in a new browser tab and displays the available meals.
